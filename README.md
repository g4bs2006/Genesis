# Genesis

Agente treinado com redes neurais (neuroevolução com currículo) controlando uma
estufa hidropônica de alface, com simulador, dashboard e projeção de lucro e
gasto. O nome vem do dispositivo Gênesis de *Star Trek II*, que transforma um
planeta morto em vida.

# 0002 — Astryx com a linguagem Lightfield como tema

**Data:** 23/11/2026 · **Situação:** aceita

## Decisão

- **Componentes:** só os do Astryx (`@astryxdesign/core`). Nada de shadcn nem
  Tailwind, nem copiado do Tesserato; o ESLint barra os imports.
- **Visual:** os tokens do Tesserato (`globals.css`, medidos no Lightfield)
  viram o tema `genesis` do Astryx, em pares `[claro, escuro]`:
  - página `#F5F5F5`, painel `#F9F9F9`, cartão branco, borda preta a 12%;
  - texto em preto a 85/72/56/42% (texto pequeno nunca abaixo de 56%);
  - raios de 5, 8 e 12px; título de 28px;
  - semáforo: ok `#45B866`, atenção `#E2B23B`, risco `#E5534B` (texto `#B8322B`);
  - cores de série: a paleta fixa do Tesserato (`--serie-*`);
  - Geist no texto, Geist Mono em números e rótulos de dado.
- **Neutros:** os do Astryx são cinza-azulados; trocados por preto/branco com
  opacidade, como no Lightfield.
- **Texto de status:** verde e amarelo puros não passam 4,5:1 como letra sobre
  branco. Ganham versões só para texto (`--ok-texto`, `--atencao-texto`); a
  bolinha e a borda usam a cor pura.
- **Fonte e compilado:** a fonte é `dashboard/src/shared/design-system/tema/genesisTheme.ts`.
  `npm run tema` gera `genesis.css` e `genesis.js` (estáticos, mais rápidos que
  injetar em tempo de execução). O CI falha se o compilado não bater com a fonte.
- **Estilo dos nossos componentes** (abas, alface, gráficos): o caminho "Plain CSS"
  do Astryx, com CSS Modules que só usam `var(--token)`. Sem compilador StyleX.
  O ESLint barra hex solto em `.tsx`.

## Consequências

- Mudar uma cor do app é mudar um token e rodar `npm run tema`.
- Componentes do Astryx que não existem (abas embaixo no celular, alface,
  gráficos) são nossos, em `shared/design-system`, sempre com claro e escuro.
